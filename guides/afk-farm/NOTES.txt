Single source: afk_farm.txt only
----------------------------
All live game code lives in afk_farm.txt. Old multi-window modules were removed.

Shareable / progressive
-----------------------
Script is gated for early-to-endgame. Helpers use have(Unlocks.*) so till,
water, fertilizer, hats, sunflowers, pumpkins, cactus, mazes, dinosaurs, and
megafarm features only run when unlocked. Power thresholds are lower before
Megafarm (30/80) and use POWER_LOW/POWER_TARGET after.

Standing constraints
--------------------
- Full window paste, not snippets
- No dictionaries in live code until Dictionaries unlocked (visited uses flat lists)
- Never iterate get_cost results
- Only the bottom loop runs across modes; main-farm loops must drain before switching
- Prefer while + index over for-in on unknown collections
- Tabs for indentation

Plant costs / feed
------------------
Carrots spend hay+wood; pumpkins spend carrots (costs rise with crop upgrades).
want_feed() checks hay/wood against feed_buffer(), then carrot stock.
Low hay/wood -> grass/trees. Low carrots (with healthy hay/wood) -> carrots.
Healthy -> hay-heavy mix + some carrots.
main_feed_wanted also scales hay/wood buffers with current carrot costs.
Already-growing feed crops finish before inventory changes select a new crop.
sunflower_rows shrinks on small farms so 8x8 keeps a feed rim (was zero free tiles).
Water when get_water() < 0.5.

Expand / pumpkin square
-----------------------
Farm size jumps (1->1x3->3x3->...->8x8->12x12).
region_n: 6x6 on sizes 8..12; half-field on larger maps.
pumpkin_care_tile: only Entities.Pumpkin+can_harvest is ready; Dead_Pumpkin
and wrong crops (leftover carrots) are cleared/replanted. Harvest at (0,0)
after the whole square is ready.

Step flow
---------
wear_straw (if Hats)
buy_all
farm_pass  # resident teams span farm_pass_count() leader cycles
buy_all only after every main-farm worker has exited
ensure_power between special modes
dino_run if Dinosaurs (+ Hats, food; shrink only with Debug_2)
maze_run if Mazes (+ substance; power gate only with Sunflowers)
buy_all between special modes

Farm
----
Main-farm regions have exclusive tile ownership. On 8x8, pumpkins keep the
6x6 square and cactus uses the remaining 2x6 rectangle beside it.
Main-farm workers use game lists/dictionaries/functions, not Python threads.
The host-side tests use Python threads only to simulate concurrent drones.

Drone shares, including the main drone: feed 15%, pumpkins 15%, sunflowers
10%, and remaining capacity for cactus. Percentages round to nearest whole
drones, with minimum coverage where capacity permits. Empty regions use none.
Mixed crops and sunflowers keep resident drones on disjoint tile ranges.
Pumpkin/cactus helpers process whole stages; no per-quantum spawn/join churn.
Single-drone/low-capacity fallbacks share local work fairly.

Pumpkins scan once and retain only unresolved tiles. Failed planting is retried
without revisiting successful plants. Helpers never harvest partial giants;
the coordinator joins all growing partitions before the single harvest, then
replants the whole region. Pending queues persist into the next growth stage.

Cactus grows to maturity, sorts disjoint rows, joins, sorts disjoint columns,
joins, and verifies maturity plus East/North ordering before chain-harvest.
Stages use only as many helpers as independent work allows. Replant afterward.

The leader handle communicates main-farm completion without mutable globals.
Feed workers keep supplying resources while remaining regions finish their
first cycle. All workers drain before buy_all or any mode changes the field.
Standalone power-restock, dinosaur, and maze routines keep their old behavior.

Dino
----
Hamiltonian cycle + apple shortcuts; late game cycle-only.
DINO_SIZE=8 only when Debug_2 can shrink; else use full farm.
Eating requires moving off the apple; never continue while sitting on one.
Prefer ending on dino full (caught own tail). Bail after DINO_IDLE_LAPS (12)
full-farm laps with no eat, or dino boxed. Step budget is DINO_MAX_STEPS.
dino_clear_tile fertilizer/till gated by unlocks.

Maze
----
MAZE_RUNS fresh mazes per step (plant bush + substance each time).
Up to MAZE_DRONES workers with direction deviation + measure guidance.
Timeout: get_tick_count if Timing, else steps max size*size*40.
