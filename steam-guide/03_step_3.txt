[b]Goal:[/b] Buy [b]Variables[/b] and the [b]2nd Expand[/b] ([b]3x3[/b]), then run a full-farm script that keeps [b]hay[/b], [b]wood[/b], and [b]carrots[/b] going, and waters dry tiles.

[b]Plant cost:[/b] every carrot spends hay + wood. About [b]1/3[/b] grass (hay), [b]1/3[/b] bushes (wood), [b]1/3[/b] carrots.

[b]Watering:[/b] You should already own [b]Watering[/b] from Step 2. This script only waters when [b]get_water() < 0.5[/b] so you do not waste tanks.

[b]Do:[/b]
[olist]
[*] Keep Step 2 running until you can buy [b]Variables[/b] ([b]35 carrots[/b]).
[*] Buy the [b]2nd Expand[/b] ([b]3x3[/b]).
[*] Rename to [b]starter_3[/b], clear, paste below, run.
[*] Buy [b]Functions[/b] ([b]40 carrots[/b]), more [b]Expand[/b] / [b]Speed[/b] / [b]Watering[/b] when cheap, then [b]Trees[/b] ([b]50 wood + 70 carrots[/b]).
[/olist]

[code]
while True:
	size = get_world_size()
	x = 0
	while x < size:
		y = 0
		while y < size:
			if can_harvest():
				harvest()

			kind = (get_pos_x() + get_pos_y()) % 3

			if kind == 0:
				if get_ground_type() != Grounds.Grassland:
					till()
			elif kind == 1:
				if get_ground_type() != Grounds.Grassland:
					till()
				plant(Entities.Bush)
			else:
				if get_ground_type() != Grounds.Soil:
					till()
				plant(Entities.Carrot)

			if get_water() < 0.5:
				use_item(Items.Water)

			move(North)
			y = y + 1
		move(East)
		x = x + 1
[/code]

[b]What each tile does:[/b]
[list]
[*] [b]kind 0[/b]: Grassland hay
[*] [b]kind 1[/b]: [b]Bush[/b] (wood)
[*] [b]kind 2[/b]: [b]Carrot[/b]
[*] Then water if the tile is under half full
[/list]

When you own [b]Trees[/b], go to [b]Step 4[/b].
