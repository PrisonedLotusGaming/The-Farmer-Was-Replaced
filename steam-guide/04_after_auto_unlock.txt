[h1]Tiny auto-buyer (starter_6)[/h1]

[b]Goal:[/b] Prove [b]unlock()[/b] works, keep hay/wood topped up so farming does not stall, then move to [b]afk_farm[/b].

[b]Must already own:[/b]
[list]
[*] Everything in [b]Unlock Order[/b] through [b]Auto Unlock[/b]
[*] [b]starter_5[/b] pumpkin farm was working
[/list]

[b]Window name:[/b] [b]starter_6[/b]

Stop [b]starter_5[/b], rename to [b]starter_6[/b], clear it, paste this, and run:

[code]
def buy():
	unlock(Unlocks.Speed)
	unlock(Unlocks.Expand)
	unlock(Unlocks.Plant)
	unlock(Unlocks.Grass)
	unlock(Unlocks.Watering)
	unlock(Unlocks.Trees)
	unlock(Unlocks.Carrots)
	unlock(Unlocks.Pumpkins)
	unlock(Unlocks.Fertilizer)
	unlock(Unlocks.Sunflowers)
	unlock(Unlocks.Cactus)
	unlock(Unlocks.Mazes)
	unlock(Unlocks.Polyculture)
	unlock(Unlocks.Dinosaurs)
	unlock(Unlocks.Megafarm)
	unlock(Unlocks.Hats)
	unlock(Unlocks.Debug)
	unlock(Unlocks.Debug_2)

def farm_once():
	size = get_world_size()
	buffer = size * size
	if buffer < 100:
		buffer = 100

	x = 0
	while x < size:
		y = 0
		while y < size:
			if can_harvest():
				harvest()

			hay = num_items(Items.Hay)
			wood = num_items(Items.Wood)
			spot = get_pos_x() + get_pos_y()

			if hay < buffer or wood < buffer:
				if hay <= wood:
					if get_ground_type() != Grounds.Grassland:
						till()
				else:
					if get_ground_type() != Grounds.Grassland:
						till()
					if spot % 2 == 0:
						plant(Entities.Tree)
			else:
				if get_ground_type() != Grounds.Soil:
					till()
				plant(Entities.Carrot)

			if get_water() < 0.5:
				use_item(Items.Water)

			move(North)
			y = y + 1
		move(East)
		x = x + 1

while True:
	buy()
	farm_once()
[/code]

[b]What farm_once does:[/b]
[list]
[*] Buffer = [b]world size squared[/b] (at least [b]100[/b])
[*] If hay or wood is under that buffer, farm the lower one (grass for hay; checkerboard trees for wood)
[*] Only plant carrots when both look healthy
[*] Waters dry tiles
[/list]

Notes:
[list]
[*] If an Unlocks.Name errors on load, delete that one unlock(...) line and try again.
[*] Do [b]not[/b] put Loops / Operators / Variables / Lists / Functions / Dictionaries / Auto Unlock in this buy list before you own them.
[/list]
