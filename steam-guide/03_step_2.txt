[b]Goal:[/b] 1st Expand ([b]1x3[/b]), unlock [b]Watering[/b] + [b]Carrots[/b], then one script that grows hay + wood + carrots together (and waters). Buy [b]Operators[/b] + [b]Senses[/b] while it runs.

[b]Expand:[/b] 1st purchase = [b]1x3[/b]. 2nd = [b]3x3[/b] (Step 3). Later sizes jump (example [b]8x8[/b] -> [b]12x12[/b]).

[b]Watering:[/b] Buy as soon as you have about [b]50 wood[/b]. Watered crops grow much faster. Free tanks refill over time. Before [b]Operators[/b], scripts just call [b]use_item(Items.Water)[/b]. After Operators (Step 3+), they only water when the tile is dry.

[b]Why mixed tiles:[/b] Each carrot spends hay + wood (hover [b]plant()[/b] for the amount). This script farms hay and wood on the other two tiles so planting can keep going.

[b]Do this in order:[/b]

[b]0) 1st Expand[/b] - buy [b]Expand[/b] ([b]30 hay[/b]) for [b]1x3[/b]. More hay on [b]starter_1[/b] first if needed.

[b]1) Bushes for wood[/b] - rename to [b]starter_2[/b], paste, run. Buy [b]Watering[/b] (~[b]50 wood[/b]) as soon as you can, then unlock [b]Carrots[/b] ([b]50 wood[/b]).

[code]
while True:
	if can_harvest():
		harvest()
	plant(Entities.Bush)
	use_item(Items.Water)
	move(North)
[/code]

After you own [b]Watering[/b], the [b]use_item(Items.Water)[/b] line starts working (harmless if you pasted it slightly early and it errors: buy Watering, then run again).

[b]2) One-time till (carrot tile only)[/b] - stand on the tile you want for carrots, run this once, then stop. Only that tile should become Soil.

[code]
till()
[/code]

[b]3) Maintain script (hay + wood + carrots + water)[/b] - paste and run. First tile in the loop must be the Soil/carrot tile you just tilled. Do not put [b]till()[/b] in this loop.

[code]
while True:
	if can_harvest():
		harvest()
	plant(Entities.Carrot)
	use_item(Items.Water)
	move(North)

	if can_harvest():
		harvest()
	use_item(Items.Water)
	move(North)

	if can_harvest():
		harvest()
	plant(Entities.Bush)
	use_item(Items.Water)
	move(North)
[/code]

If carrot [b]plant()[/b] does nothing, you are short on hay or wood. Leave this running; the hay and bush tiles refill it.

[b]4) Buy while it runs:[/b]
[list]
[*] [b]Operators[/b] ([b]150 hay + 10 wood[/b])
[*] [b]Senses[/b] ([b]100 hay[/b]) right after
[*] More [b]Watering[/b] ranks if cheap (more tanks)
[*] [b]Speed[/b] if cheap
[*] Skip 2nd Expand until Step 3
[/list]

Then go to [b]Step 3[/b].
