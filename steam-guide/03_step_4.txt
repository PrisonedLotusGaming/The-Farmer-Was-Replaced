[b]Goal:[/b] Better wood from a [b]few[/b] spaced trees, plus hay and carrots. Grind [b]Lists[/b], then unlock [b]Pumpkins[/b].

[b]Plant cost:[/b] carrots spend hay + wood. Hay tiles refill hay; trees refill wood (trees drop more wood than bushes, so you do not need many).

[b]Trees:[/b] Only about [b]1/4[/b] of tiles are trees, on a spaced grid so none sit north/south/east/west of another tree (adjacent trees grow much slower).

[b]Do:[/b]
[olist]
[*] Rename to [b]starter_4[/b], clear, paste, run.
[*] Buy [b]Lists[/b] ([b]500 carrots[/b]). Buy more [b]Expand[/b] before that if you can.
[*] Buy [b]Pumpkins[/b] ([b]500 wood + 200 carrots[/b]) when ready. Buy [b]Speed[/b] / [b]Grass[/b] / [b]Watering[/b] when cheap.
[/olist]

[code]
while True:
	size = get_world_size()
	x = 0
	while x < size:
		y = 0
		while y < size:
			if can_harvest():
				harvest()

			spot = get_pos_x() + get_pos_y()

			if spot % 4 == 0:
				if get_ground_type() != Grounds.Grassland:
					till()
				plant(Entities.Tree)
			elif spot % 4 == 1:
				if get_ground_type() != Grounds.Grassland:
					till()
			else:
				if get_ground_type() != Grounds.Soil:
					till()
				plant(Entities.Carrot)

			if get_water() < 0.5:
				use_item(Items.Water)

			move(North)
			y = y + 1
		move(East)
		x = x + 1
[/code]

[b]Tile guide:[/b]
[list]
[*] [b]spot % 4 == 0[/b]: [b]Tree[/b] (sparse + not beside other trees)
[*] [b]spot % 4 == 1[/b]: Grassland [b]hay[/b]
[*] [b]spot % 4 == 2 or 3[/b]: [b]Carrot[/b]
[*] Water any tile under half full
[/list]

When you own [b]Pumpkins[/b], go to [b]Step 5[/b].
