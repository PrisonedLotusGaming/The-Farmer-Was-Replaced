The full script is too long for Steam, so it lives on GitHub as [b]afk_farm.txt[/b].

[b]Must already own:[/b]
[list]
[*] Everything in [b]Unlock Order[/b] through [b]Auto Unlock[/b]
[*] [b]starter_6[/b] runs without errors
[/list]

[b]Window name:[/b] [b]afk_farm[/b]

[b]Install from GitHub[/b]
[olist]
[*] Open: [url]https://github.com/PrisonedLotus/the-farmer-was-replaced-afk-farm[/url]
[*] Open [b]afk_farm.txt[/b] (Raw view is easiest to copy).
[*] Stop [b]starter_6[/b].
[*] Rename the code window to [b]afk_farm[/b].
[*] Clear it, paste the full file, run it.
[*] Leave it AFK.
[/olist]

The same repo also has [b]starter_1.txt[/b] through [b]starter_6.txt[/b] if you want the starters from files instead of this guide.

From here, [b]afk_farm[/b] farms and calls [b]unlock()[/b] on its PRIORITY list when you can afford items. It keeps hay/wood topped up for carrot plant costs, grows a solid pumpkin square for giants, and waters as it goes. [b]Megafarm[/b] is not required to start; extra drones turn on automatically after you unlock it.
